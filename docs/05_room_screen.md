# 05: ルーム画面 実装

## 依存: 03（RoomService 完了後）
## 並列グループ: D
## 並列実行可能: 06, 07, 08 と同時実行可

## やること

### 新規ファイル: `lib/screens/room_screen.dart`

### 画面構成

#### 初期状態: モード選択
- 「部屋を作る」ボタン
- 「部屋に入る」ボタン
- 戻るボタン（ホームへ）

#### 部屋を作るモード
1. RoomService.createRoom() で6桁コード生成
2. コードを大きく表示（コピー可能）
3. 「待機中... 相手の参加を待っています」表示
4. RoomService.listenForStatus() で相手の参加を監視
5. 相手が参加したら（status: "ready"）:
   - GameProvider にルーム情報セット（playerNumber=1）
   - 召喚画面へ遷移

#### 部屋に入るモード
1. 6桁コード入力フォーム
2. 「参加する」ボタン
3. RoomService.joinRoom(code) を実行
4. 成功:
   - GameProvider にルーム情報セット（playerNumber=2）
   - 召喚画面へ遷移
5. 失敗:
   - 「部屋が見つかりません」または「既に対戦が始まっています」エラー表示

### UIスタイル
- 既存のアプリトーンに合わせる（白ベース + 青差し色 + 黄色アクセント）
- コード表示は大きくモノスペースフォントで
- ローディング中はスピナー表示

### エラーハンドリング
- タイムアウト（60秒待っても相手が来ない場合）→ 「タイムアウトしました」表示、部屋削除
- ネットワークエラー → リトライ案内

## 完了条件
- 部屋作成→コード表示→待機が動作する
- コード入力→参加が動作する
- 相手参加時に召喚画面へ遷移する
- エラー時に適切なメッセージが表示される
