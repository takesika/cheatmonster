### 2. オンライン対戦の通しテスト
2台のシミュレータ（または実機）で以下を実施:

#### 正常系
1. Player1: 「対人対戦」→「部屋を作る」→ コード表示
2. Player2: 「対人対戦」→「部屋に入る」→ コード入力 → 参加
3. 両者: 召喚画面でモンスター作成 → 「準備完了！」
4. 両者: 待機画面 → 相手の準備完了を検知 → バトル画面へ
5. Player1: 「戦う！」でジャッジ実行
6. 両者: 結果が表示される（WIN/LOSEが正しく反転している）
7. 「もう一度」でホームに戻る

#### 異常系
- 存在しないコードで参加 → エラーメッセージ
- 相手が召喚前に切断 → タイムアウト → ホームへ
- Player1がジャッジ前に切断 → Player2側でタイムアウト
- ネットワーク切断時の挙動
